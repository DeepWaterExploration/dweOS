# dweOS

dweOS is an optional software interface designed to run on underwater systems like a Raspberry Pi, our Subsea Vision Computer line, or BlueOS as an extension. It acts as a powerful companion to DeepWater Exploration cameras, extending their functionality and providing a seamless, out-of-the-box experience.

![dweOS main UI screenshot](https://mintcdn.com/deepwaterexplorationinc/7_JU7cua5Oe3RepH/dwe-os/pages/images/dwe-os-demo-page.png)

## Features

- RTP camera streaming for low-latency camera streams
- Advanced camera controls (See https://docs.dwe.ai/dwe-os/pages/camera-controls for more information)

For more information, please see our [quickstart guide](https://docs.dwe.ai/dwe-os/guides/quickstart).
